## Descrição do Bug

### Comportamento Atual (Errado)

O projeto contém referências à plataforma Lovable (ferramenta que gerou a estrutura inicial), incluindo:

- Possíveis dependências no `package.json`
- Comentários gerados automaticamente no código
- Configurações específicas da plataforma
- Metadados que identificam a origem do projeto
- Arquivos ou pastas de configuração do Lovable

Essas referências são desnecessárias e podem causar confusão sobre a origem e manutenção do projeto.

### Comportamento Esperado (Correto)

Projeto completamente independente, sem qualquer referência ao Lovable, pronto para evolução autônoma pela equipe AILA.

### Passos para Reproduzir

1. Clonar o repositório
2. Buscar por "lovable" (case-insensitive) em todos os arquivos
3. **Resultado:** Encontrar referências que deveriam ser removidas

### Evidências

| Tipo | Link/Descrição |
|------|----------------|
| Contexto | Projeto foi gerado inicialmente pela plataforma Lovable |
| Necessidade | Limpeza antes de iniciar desenvolvimento via PRDs |

## Análise da Causa Raiz

### Hipótese Principal

O projeto foi scaffolded pela plataforma Lovable, que injeta automaticamente referências, comentários e configurações próprias nos arquivos gerados.

### Arquivos/Componentes Suspeitos

| Arquivo | Motivo da Suspeita |
|---------|-------------------|
| `package.json` | Metadados (name, author, homepage), dependências específicas |
| `vite.config.ts` | Plugins ou configurações do Lovable |
| `index.html` | Meta tags, comentários, scripts externos |
| `README.md` | Instruções de deploy, badges, links para Lovable |
| `src/**/*.tsx` | Comentários `// Generated by Lovable` ou similares |
| `.lovable/` ou `lovable.json` | Pasta/arquivo de configuração da plataforma |
| `.env*` | Variáveis de ambiente específicas |
| `tsconfig*.json` | Configurações específicas |

### Investigação Necessária

- [ ] Buscar "lovable" (case-insensitive) em todo o projeto
- [ ] Verificar existência de pasta `.lovable` ou arquivo `lovable.json`
- [ ] Analisar `package.json` para dependências e metadados
- [ ] Verificar comentários automáticos nos arquivos `.tsx`
- [ ] Checar `index.html` por scripts ou meta tags externas
